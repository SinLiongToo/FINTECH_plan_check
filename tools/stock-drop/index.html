Taiwan Stock Drawdown Explorer — User Guide

Self-contained tool for visualising historical peak-to-trough drawdowns across 15 major Taiwan stocks and the TAIEX index. Built-in weekly simulated data works offline. Import a daily CSV or fetch live for real prices.

Quick Start

  • Click any stock chip to switch the chart
  • Drag Drop ≥ slider (2–60%) to surface corrections
  • Click a range button (3M → All, back to 1967 for TAIEX)
  • Hover over chart to read date, price, and % from peak
  • Edit episode card titles and notes inline
  • ⤓ Export MD downloads your annotated notes

How Episode Detection Works

An episode closes when either:

  • New all-time high — price exceeds the previous peak
  • Trough recovery ≥ threshold% — price rebounds the same % from the trough

Without the second rule, TAIEX's 1990 crash (−80%) stays “open” until 2021, swallowing all crashes in between. With it, each bear market is identified separately.

ConditionCapturesExample
New ATHFull recovery2003 SARS: ATH recovered by 2007
+threshold% from troughPartial recovery1990 crash: bounced off 2,485 in 1991

⚠ Threshold 10–20% gives historically meaningful separation. Very low thresholds may split one crash into multiple episodes.

Editable Labels

  • Click any card title or notes textarea to edit inline
  • Known events (1990, 2008, 2020…) are pre-labelled by peak year
  • Click + Add annotation for custom events
  • Reset labels restores all defaults

Daily Data — CSV Import (⤒ Import CSV)

  1. Go to finance.yahoo.com
  2. Search ticker, e.g. 2330.TW or ^TWII
  3. Click Historical Data → set date range → Download
  4. Click ⤒ Import CSV, drop the file, then Apply to chart

Yellow ● CSV badge confirms daily data is active. Accepts Yahoo Finance (YYYY-MM-DD) or Stooq (MM/DD/YYYY) formats. Switching stocks or reloading reverts to built-in data.

Updating Built-in Data

Open this HTML in a text editor. Find const RAW = { near the top of the <script> block. Each stock is an array of [“YYYY-MM-DD”, price] weekly points. To add recent data, append new weekly points at the end in chronological order.

// Example — extend TSMC to end of 2026:
"2330.TW": [ ...existing points...,
  ["2026-10-01", 1820],
  ["2026-10-08", 1835],
  ... ]

⚠ Points must be strictly chronological. The data uses weekly spacing (every 7 days).

Data Disclaimer

  • Built-in data is synthetically generated via Brownian bridge between known historical anchor points (peaks, troughs from TWSE/Bloomberg records) — not real historical closes
  • TAIEX anchor data starts from 1967; individual stocks from 2005–2008
  • Pre-1990 data is especially approximate — treat as indicative, not precise
  • Nothing in this tool constitutes financial advice
